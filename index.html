      FAQ

      Frequently asked questions

      Are my files uploaded or stored on any server?

      Never. Transmute is 100% client-side. File conversion runs inside your browser using JavaScript and HTML5 Canvas APIs. You can even disconnect your internet connection while converting and it will work smoothly.

      Is there any file size limit or daily cap?

      There are no arbitrary website limits, subscriptions, or paywalls. You can convert as many files as your device memory can accommodate.

      How does the clipboard paste feature work?

      Take a screenshot using your system shortcut (Win + Shift + S on Windows or Cmd + Shift + 4 on Mac), then click anywhere on this page and press Ctrl + V. The image will immediately enter the queue ready for conversion.

      Can I reorder pages for the Images to PDF converter?

      Yes. In Images to PDF mode, each uploaded file shows Up (↑) and Down (↓) buttons so you can arrange your pages in the exact sequence you desire before generating the document.
